# 시장에 대한 생각

분기마다 매크로와 데이터로 시장을 읽고, 뷰와 목표 구간으로 예측을 남긴 뒤 91일 후 스스로 채점하는 기록입니다.

- 홈페이지: `index.html`
- 예측 장부: [`predictions.csv`](predictions.csv). 한 번 기록한 예측은 수정하지 않습니다. 이 저장소의 커밋 이력이 기록 시점의 증거입니다.
- 서한 원본: [`letters/`](letters/)

채점: 뷰 점수(적중 1.0, 한 칸 차이 0.5, 그 이상 0) × 50% + 목표 구간 적중 × 50%.
구간 폭(`width_ratio` = 목표 구간 폭 ÷ 기록 시점 다음 분기 1σ 범위 폭)을 함께 공개합니다.

개인적인 시장 기록이며 투자 권유가 아닙니다.
